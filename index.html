    How LetterDesk wins replies

    1
    Evidence-first targeting. We merge three scholarly APIs so every claim in your letter (paper title, DOI, year, topic overlap) is verifiably true. Professors spot generic spam instantly — specifics don't lie.
    2
    Live email verification. Using Google DNS-over-HTTPS we check MX records and mailbox signals, so your effort isn't wasted on dead addresses.
    3
    The 150-word rule. Busy PIs reply to letters they can read in 30 seconds. Our meter blocks sending-worthy drafts over 150 words and strips clichés like “I hope this finds you well”, “delve”, “game-changer”.
    4
    Three generation modes. Local templates (instant, offline), free Groq/Llama 3 rewriting (bring your free API key), or the ChatGPT Prompt Builder which packages everything into one perfect prompt — no key needed.
    5
    Know your market rate. The stipend panel shows typical funded-position pay by country so you can evaluate offers quickly.

    This portal is 100% static (HTML + Tailwind CDN + vanilla JS). Pick any free host below — no server needed.

    1. Click Download Site (.zip) below — it bundles index.html, css/ and js/.
    2. Unzip it, then open app.netlify.com/drop.
    3. Drag the unzipped folder onto the page. You instantly get a live *.netlify.app URL. No account needed for a temporary site; sign in free to keep it forever.

git push origin main
# 2) In the repo: Settings → Pages → Source: "Deploy from a branch"
#    Branch: main / (root) → Save. Live at:
# https://<username>.github.io/<repo>/
    Option C · Vercel / Cloudflare Pages ›

    Both accept the same static folder: import the GitHub repo (or upload directly), set Framework preset: Other, output directory “.” (root), no build command. Cloudflare: pages.cloudflare.com · Vercel: vercel.com/new
